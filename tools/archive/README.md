# Historical tools

`investigations/` contains one-off animation/viewmodel probes, preview/capture scripts and
superseded build/regen commands. `character-studies/` contains the old segment/alternate-rig
generators. These files are retained as historical evidence, not supported entry points.
Their old paths/types/build directories may be stale; don't execute them against the accepted
checkpoint without deliberately reviewing/updating their scope.

Supported tooling lives in `tools/build`, `tools/qa`, `tools/maintenance`, `tools/pipeline` and
`tools/blender`. See `docs/DEV_ENVIRONMENT.md`. Automated historical "visual checks" do not
substitute for human visual or game-feel acceptance.
