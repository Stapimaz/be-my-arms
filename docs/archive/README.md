# Development archive — historical, not current instructions

These reports preserve experiments, decision evidence and limitations from earlier work.
They may contain obsolete paths, types, commands, acceptance language and design assumptions.
**Do not treat them as the current roadmap, architecture, environment guide or visual approval.**

- `milestones/`: former numbered milestone reports, control/presentation passes, Transport
  probe records and old probe source copies. Evidence is retained, not silently rewritten.
- `planning/`: snapshots of the superseded concept/roadmap/technical plan before normalization.
- `normalization/`: exact move/name mapping and objective reference-preservation record for
  the pre-Phase-3 repository refactor. One-time scripts are in `tools/archive/normalization`.
- Current authority: root `GAME_CONCEPT.md`, `ROADMAP.md`, `TECHNICAL_PLAN.md` and
  `docs/DEV_ENVIRONMENT.md`.

Playable prototype/sample scenes remain in `Assets/Scenes/Samples`, and old character studies
in `Assets/Art/Characters/Samples`. Historical investigation scripts live in `tools/archive`.
They are not required reading or runnable setup steps for a fresh context.
